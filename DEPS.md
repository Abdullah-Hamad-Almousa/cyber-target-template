# Dependencies & Assets

This website is a **zero-build, single-file** project. No npm packages, no bundlers, no external build tools.

## External CDN Dependencies

1. **Google Fonts**
   - **Inter** (weights: 400, 500, 600, 700)
   - **Cairo** (weights: 400, 500, 600, 700)
   - URL: `https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Cairo:wght@400;500;600;700&display=swap`

2. **Lucide Icons**
   - Loaded via CDN script tag
   - URL: `https://unpkg.com/lucide@latest`
   - Icons used: `shield-check`, `activity`, `alert-triangle`, `terminal`, `cloud`, `eye`, `clipboard-check`, `users`, `check`, `image`, `menu`, `x`, `sun`, `moon`, `shield`, `mail`, `phone`, `map-pin`, `linkedin`, `twitter`, `github`

## No Other Dependencies

- No Node.js / npm
- No React, Vue, Angular, or other frameworks
- No build step or bundler
- No CSS preprocessor
- No jQuery

## Assets You Need to Source

The site includes 4 image placeholder blocks. Replace each placeholder `<div>` with a real `<img>` (or `background-image`) using the guidance in the HTML comments above each placeholder.

1. **Hero Image** (`images/hero-soc.jpg` suggested)
   - 1200×600px (16:9)
   - Cinematic wide shot of a modern SOC

2. **Services Banner** (`images/services-banner.jpg` suggested)
   - 1400×500px
   - Split composite: hacker silhouette (left) vs cybersecurity analyst (right)

3. **Why Us Image** (`images/why-us.jpg` suggested)
   - 800×500px (landscape)
   - Close-up of cybersecurity professional's hands on a laptop

4. **CTA Background** (`images/cta-bg.jpg` suggested)
   - 1920×600px (background / cover)
   - Aerial city at night with glowing fiber-optic light trails

## How to Run

Simply open `index.html` in any modern web browser. No server required.
